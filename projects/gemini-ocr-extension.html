Gemini OCR Extension

〜 画像内のあらゆる文字を、AIの「目」で自在にテキスト化 〜

【Hook】

標準的なOCRでは太刀打ちできない、画像内の特殊フォントや複雑なUIテキストをGeminiのマルチモーダル能力で正確に抽出。

【Demo】

Chromeブラウザ上で範囲を選択するだけで、背後でGemini APIが走り、構造化されたテキストとして即座にクリップボードへコピーされます。

【Background】

Web上のデザイン資料や、コピーガードのかかったドキュメントから情報を抽出する際の手間を解消するために開発されました。「見たまま」を読み取る能力を、ブラウザの拡張機能という形で日常のワークフローに統合しました。

【Logic】

  • ブラウザキャプチャ: chrome.tabs.captureVisibleTab を利用して選択範囲を高精度に画像化。
  • マルチモーダルAI連携: Gemini 1.5 Flash (Vision) API を活用し、画像内のコンテキストを理解した上での文字起こしを実現。
  • シームレスなUX: React + Vite で構築されたポップアップUIにより、設定不要で直感的に操作可能。
